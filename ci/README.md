# Concourse scripts (superseded)

These scripts belong to the former Concourse release process: `create-release.sh` made a signed tag and moved the `VERSION` in `package.yml`, and `package.sh` built a tarball for Artifactory.

Releases are now made with GitHub Actions, see [docs/RELEASE.md](../docs/RELEASE.md). The scripts are kept for reference and are not maintained. They may be removed once nothing uses them.
